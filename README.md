# Bài thực hành PHP

Repository lưu các bài thực hành của học phần PHP.

## Cấu trúc

```text
TenSV_MaSV/
└── Buoi_1/
    ├── bai1.php
    ├── bai2.php
    ├── bai3.php
    └── bai4.php
```

## Chạy bài

Mở terminal tại thư mục repository và chạy:

```bash
php -S localhost:8000
```

Sau đó mở một trong các địa chỉ:

- `http://localhost:8000/Buoi_1/bai1.php`
- `http://localhost:8000/Buoi_1/bai2.php`
- `http://localhost:8000/Buoi_1/bai3.php`
- `http://localhost:8000/Buoi_1/bai4.php`

Trước khi nộp, đổi tên repository từ `TenSV_MaSV` thành tên và mã sinh viên thật, ví dụ `DoanBinh_012345`, đồng thời đặt repository ở chế độ Public.
