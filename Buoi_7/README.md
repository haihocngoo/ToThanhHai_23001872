# Bài tập thực hành buổi 7 - Vue 3

Ba bài trong đề được đặt trong cùng thư mục `Buoi_7`:

1. `bai1.html`: danh sách sản phẩm với tìm kiếm, lọc danh mục, sắp xếp, thêm, xóa và thống kê.
2. `bai2.html`: danh mục sử dụng component `<the-san-pham>` trong `components/TheSanPham.js`.
3. `bai3.html`: giỏ hàng sử dụng component `<dong-gio-hang>` và các sự kiện `doi-so-luong`, `yeu-cau-xoa`.

Mở `index.html` bằng trình duyệt rồi chọn bài. Các trang tải Vue 3 từ CDN nên cần kết nối Internet; không cần Node.js hay PHP khi chạy. Dữ liệu chỉ tồn tại trong phiên trang, tải lại sẽ trở về dữ liệu mẫu.

Kiểm tra Bài 3: 2 bút × 5.000 đ và 3 vở × 12.000 đ cho tổng 5 món, 46.000 đ.
